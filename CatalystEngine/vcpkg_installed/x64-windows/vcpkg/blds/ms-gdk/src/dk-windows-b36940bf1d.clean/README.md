# Microsoft Game Development Kit (GDK)

**The Microsoft Game Development Kit (GDK) contains the tools, libraries, and documentation needed to build games for [Xbox Game Pass for PC on Windows](https://www.xbox.com/en-US/xbox-game-pass/pc-games), Xbox consoles (Xbox Series X|S, Xbox One), and [cloud gaming with Xbox Game Pass Ultimate]( https://www.xbox.com/en-US/xbox-game-pass/cloud-gaming).**

# Documentation

See [Microsoft Learn](https://learn.microsoft.com/gaming/gdk/) for the Game Development Kit (GDK) documentation.
